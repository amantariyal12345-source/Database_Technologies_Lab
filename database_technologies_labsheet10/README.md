## Requirements
- MongoDB Server and MongoDB Shell (`mongosh`)
- Python 3
- Flask
- PyMongo

Install Python dependencies for Flask questions:
```bash
pip install flask pymongo
```

Run the MongoDB setup in Q1 before testing the Flask exercises. Q13 contains the combined mini-application and its project structure.
