# Database Technologies Lab Sheet 1

Course code: MCA105P  
Topic: Basic DBMS Commands — 50 Practice Problems  
Dialect: MySQL

Each question has its own `.sql` file (`Q01.sql` through `Q50.sql`). The original question is included as a SQL comment at the top of each file, followed by the solution.

## How to use
1. Open the required `Qxx.sql` file.
2. Copy and run the SQL in MySQL Workbench or your MySQL environment.
3. Some `ALTER` questions assume the table/columns mentioned in the question already exist.
4. Run table-creation questions before later questions that modify those tables, where applicable.

Note: MySQL-specific syntax is used, including `ENUM`, `RENAME COLUMN`, `CHANGE COLUMN`, and `CREATE TABLE ... LIKE`.
