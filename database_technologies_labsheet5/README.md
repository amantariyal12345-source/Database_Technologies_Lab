# Database Technologies Lab Sheet 5

This folder contains one `.sql` file for each of the 25 questions in the lab sheet.

## Before running
1. Open MySQL/MariaDB.
2. Run the database and table creation commands and sample-data INSERT statements from the lab sheet setup.
3. Make sure the database is named `CollegeJoinDB`.
4. Run each question file separately.

Each file contains the question as an SQL comment followed by its SQL solution. Q8, Q10, and Q11 intentionally use the comparison conditions specified in the questions; they may return multiple matching grades because they do not apply the complete salary-range condition.
